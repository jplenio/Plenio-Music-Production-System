@ card 10 · Song API
Your own programs can make songs too. This is the Song API.

@ card Plenio at a glance
Plenio is a complete song production suite, right on your own PC. [pause:0.3s] And it brings a player of its own, made for these songs, with a party mode where everyone makes songs from their own phone, straight into the playlist.

@ card In this video
In this video: the Song API. One request makes a song; you follow it, download its files, and make it again.

@ The Song API is part of Plenio
The Song API is part of Plenio, on your running ComfyUI. Any program that speaks HTTP can make songs with it.

@ Its reference lists every call
Its reference lists every call, every answer and every field. And a guide takes you from the first request all the way to the files.

@ The address of your ComfyUI
The address of your ComfyUI, then slash plenio, slash A P I, slash v one. It answers with its version, Plenio's version, and the templates it can make.

@ A template’s fields come from the template itself
A template's fields come from the template itself. Change the workflow, and the API follows.

@ Make a song: the template, a few fields
To make a song, send the template, a few fields, and a name for your program. The answer is the job, queued.

@ The Idempotency key makes a request safe
The idempotency key makes a request safe to send again: the same key never makes a second song.

@ Follow it with wait
Follow it with wait: the answer comes the moment something changes. No need to ask every second.
