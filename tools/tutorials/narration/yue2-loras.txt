@ YuE2 has two halves
Yu-eh two has two halves. A LoRA on the planner shapes the plan: structure, melody, genre. One on the acoustic model shapes the sound.

@ The node reads which half
The node reads which half a file is for, and applies it there. One strength per LoRA is enough.

@ Put a LoRA into models/loras
Put a LoRA into models, slash loras, and choose it. Ours is an instrumental LoRA, trained on Yu-eh two's planner.

@ strength: 1 as trained
Strength: one, as trained. Zero is off. A LoRA's card says what suits it.
