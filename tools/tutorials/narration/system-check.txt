# Narration of system-check.mjs (Tutorial 0 · System Check). Format: lib/voice.mjs.

@ card 0 · System Check
Welcome to Plenio! Before you make any music, let's check that ComfyUI is ready for it.

@ Open the template browser
Open the template browser.

@ Plenio’s templates are listed
Plenio's templates are listed under Extensions, in their own folder.

@ 0 · System Check: start here
Template zero is the System Check. [pause:0.4s] It's the right place to start, right after installing Plenio.

@ The template is one node
Just one node, and a note.

@ About this template
The note lists everything the check looks at. [pause:0.5s] Versions, the graphics card, the model files, and more.

@ detail: “summary”
Detail: a readable summary, or the full facts for a bug report.

@ Press Run.
Now, press Run. [pause:0.4s] It only takes a moment.

@ The verdict first
The verdict first, then the versions of ComfyUI, Plenio, Python and torch.

@ The GPU with its memory
Below that: the graphics card and its memory, the system RAM, the Python packages, and the download policy.

@ The templates: for each one
For every template: are its model files installed? If not, you see what's missing, and how big it is.

@ Every model file the templates load
Here's every model file the templates use: with its folder, its size, its licence, and its status.

@ The hardware table:
The hardware table matches model files to graphics memory. [pause:0.3s] The row for this machine is highlighted.

@ And the recommendations
And finally, recommendations for this machine. Nothing changes on its own: you pick the files in the loader nodes.

@ The check only reports
The check only reports. It never changes a setting, and never downloads anything.

@ card Next: 1 · YuE2 · Song
All green? Then let's make music. Next up: template one, YuE2 Song.
