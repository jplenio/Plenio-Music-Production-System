# Narration of system-check.mjs (Tutorial 0 · System Check). Format: lib/voice.mjs.

@ card 0 · System Check
Welcome to Plenio! Before we make any music, let's make sure ComfyUI is ready for it.

@ card Plenio at a glance
Plenio is a complete song production suite, right on your own PC. [pause:0.2s] Let it make a whole batch of finished songs on its own, [pause:0.2s] or take every word and every note into your own hands, DAW style. It's the perfect home for YuE2. [pause:0.3s] And it brings a player of its own, made for these songs, with a party mode where everyone makes songs from their own phone, straight into the playlist.

@ card In this video
In this video: one run that checks your ComfyUI for Plenio, the models it finds and misses, and the report.

@ Open the template browser
First, open the template browser.

@ Plenio’s templates are listed
Plenio's templates have a folder of their own, down under Extensions.

@ 0 · System Check: start here
Template zero is the System Check. [pause:0.3s] It's the place to start, right after you install Plenio.

@ The template is one node
It's a single node, with a note beside it.

@ About this template
The note lists what the check looks at: the versions, the graphics card, the model files, and more.

@ detail: “summary”
Detail picks a readable summary, or the full set of facts for a bug report.

@ Press Run.
Now press Run. [pause:0.3s] This only takes a moment.

@ The verdict first
The verdict first, then the versions of ComfyUI, the frontend, Plenio, Python and torch.

@ The GPU with its memory
Then the graphics card and its memory, the RAM, the packages, and the download policy.

@ And the local LLMs Plenio found
It lists the local language models it found: GGUF files, LM Studio or Ollama. Any of them can be your writer model.

@ The templates: for each one
For every template, you see whether its model files are installed. If something's missing, it says what, and how big it is.

@ Every model file the templates load
Here's every model file the templates use, with its folder, its size, its licence and its status.

@ The Plenio assets:
Then the Plenio assets: the lyrics recognition, Qwen three A S R, its forced aligner and the Whisper fallback, with the folder they live in, and whether they're there.

@ The hardware table:
The hardware table matches the model files to your graphics memory. [pause:0.3s] The row for this machine is marked.

@ And the recommendations
Last come the recommendations for this machine. Nothing changes by itself: you choose the files in the loader nodes.

@ The check only reports
The check only reports. It never changes a setting, never loads a model, and never downloads one.

@ card Next: 1 · YuE2 · Song
All green? Then let's make some music. Next up: template one, YuE2 Song.
