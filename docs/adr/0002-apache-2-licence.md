# ADR-0002: Apache-2.0 for Plenio's code

- Status: accepted
- Date: 2026-09-25
- Design reference: D-02

## Context

The legacy toolkit was MIT. Plenio vendors Apache-2.0 upstream code (YuE `abc_tools.py`).

## Decision

Plenio's code is licensed under Apache-2.0 with a NOTICE file.

## Consequences

Explicit patent grant; the same licence as the vendored upstream code. Model weights keep their own licences, surfaced in the docs and the release record.
