## Deviations from the design (recorded in the design documents)

- Writer answer format: labels `TITLE:` ... instead of headings; unlabelled answers are inferred and reported.
- Export receives only the Song Sheet reports (draft/Score Tools reports would force the writer/planner to run for manual documents).
- Promoted blueprint inputs that feed inner widget inputs are widgets on the wrapper even when linked (frontend 1.53); the graph builder derives this.
- `cfg_scale` is serialised by the frontend (1.0) even when planning is off, like the native blueprint.
- *Takes* block (native loops) deferred to Phase 4B with Check Vocals; Phase 3 ships one take per run.
- Song Brief: combos (length, vocals) stay the user's choice; templates fill only empty text fields.

## Not verified

- Listening quality (V4), vocal absence in instrumental audio (G4/G5), Linux, CI on GitHub (no remote).
