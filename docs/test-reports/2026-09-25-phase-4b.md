## 5. Defects found by the real runs and fixed

| Finding | Fix | Test |
|---|---|---|
| A native loop whose body is blocked by a waiting Song Sheet never finishes - the queue hung with the template's default *stop for review* (ComfyUI 0.37.0) | the Takes loop starts with the final lyrics (`initial_iteration_value`), so a waiting sheet blocks the loop itself | host tests for both sheets |
| Export failed: ComfyUI writes NaN fingerprints of loop nodes into the prompt | records keep only class, inputs and title per node | unit + host |
| Frontend 1.53.6 restores a DynamicCombo-first node wrongly (Score Tools *fit length* 75 s -> `operation = 75`) | Plenio wraps `configure` of its DynamicCombo nodes and re-applies the saved values | frontend unit tests, browser check |
| Whisper invented "Thank you." at the end of a vocal region inside the chorus | weak-segment rule (<= 3 words, avg_logprob < -0.7, a word below p 0.2), reported | unit test with the recorded segment |
| New lyrics unintelligible: too few syllables, voice outside the melody's range | text-sheet warnings (syllables per note 0.85-1.3, voice register), per-line targets and the register in the prompt | unit tests calibrated on the runs |
| "baritone" not recognised as a vocal character | voice types in the style vocabulary, instruments named after them excluded | unit tests incl. all shipped templates |
| Adapter and SheetSage2 licences missing from records | licences of referenced model files | unit test, real records |
| A clean take that stopped mid-phrase was preferred over a clean take that ended | ranking prefers a clean take with a natural ending | unit test |
| The ASR note was lost after a reload with a full cache hit | notes are stored by draft hash and served by a route | host test, browser check |
| Instrumental length advice told the user to shorten the lyrics | instrumental advice names *fit length* | unit test |

## 6. Limits and open points

- YuE2 renders a take up to the render ceiling (1.25 x the score) and may stop mid-phrase; Check Vocals reports it and the ranking avoids it when there is a better take. Fading out is the Master stage's job (Phase 7).
- New lyrics depend on the writer model following the syllable targets; Gemma 4 E4B follows them only partly. The sheet warns; the user corrects or re-drafts.
- The sung-lyrics check measures the take, not the musical quality.
- Not built in 4B: play-section in the editor, Qwen3-ASR as an engine, early-exit retries, vocal separation (C2). German test songs were not required by the owner.
- Linux and cards other than 16 GB are unverified; CI still has no remote (Phase 2 note).
