# Mutation runs (phase 9.3), 2026-11-12

`tools/mutation.py` (mutmut 2.5.1 in `.devdeps`, with the owner's permission) mutates one module at a time in an export of the committed tree (`git archive HEAD`) and runs the unit tests that exercise it; `tools/mutation_runner.py` ends a run that hangs after 180 s (mutmut's own timeout did not end a hung process on Windows: one `fetch.py` mutant stalled the first run for an hour). The raw results with every survivor's diff: `docs/test-reports/data/mutation-before.json`.

## What the survivors were, and what was done

- **Messages and texts** (most of the survivors in every module: a message wrapped in `XX`, a word of a hint changed) - not behaviour; left as they are. A test that pinned every sentence would make every wording change a test change.
- **Equivalent mutants** - the result cannot differ: `_CHUNK` sizes in `fetch.py`, an IPv6 zone split (`split("%", 2)`: Python 3.12 parses a scope id itself), `missing_ok=False` on a file that always exists at that point, the default of a field that is always passed, the absolute gate at -70 against -71 LUFS (no block of a real signal lies between them).
- **Tests added** for every survivor that changes behaviour:
  - `access.py` (`tests/unit/test_route_access.py`): an origin without a port has its scheme's port (80, 443), a port that is no port is refused, an origin with no Host is refused, a local route without `what` or `hint` is refused, the route table cannot be changed.
  - `modelplan.py` (`tests/unit/test_modelplan.py`): a card with exactly a file's threshold runs it (fully, or with offloading), with no card only a file that needs none runs, files that tie are ordered by size, an installed file one quality rank below the best is kept and two below are replaced (per preference), alternatives exclude the pick, a slow file and a better one are both said.
  - `fetch.py` (`tests/unit/test_assets.py`): a resumed download asks only for the rest (the test server notes the `Range` header), a host that sends everything again overwrites the partial file instead of appending to it, a whole partial file is not asked for again and a too long one is replaced, progress runs over every file of an asset, the size in the message is in MiB. The resume tests had been there; the runner had left out the `io`-marked ones - it now runs all of a module's tests.
  - `loudness.py` (`tests/unit/test_loudness_measured.py`): values worked out by hand instead of the pyloudnorm oracle (`test_audio.py` skips without it) - a steady tone has no range, two levels 10 dB apart have 10 LU, a level 25 LU below is gated out of the range, the loudness follows the gain exactly, a peak between two samples is found at 44.1, 48, 96 and 192 kHz across the meter's blocks, above 192 kHz the sample peak is the true peak, a mono sine reads -23 LUFS at -20 dBTP (PLR 3.01 dB), silence is no measurement.
