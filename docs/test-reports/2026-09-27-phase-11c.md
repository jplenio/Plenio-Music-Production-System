### L1 - Refine (`sr_study.py`), material: a 48 kHz YuE2 take (reference) and the same MiniMax take (target)

Simulation set (the reference band-limited at 14.5 kHz; LSD compares the 16-24 kHz band with the reference):

| Arm | LSD 16-24 kHz | fizz flatness | loudness change | true peak | RTF | peak VRAM |
|---|---|---|---|---|---|---|
| resample only | 113.39 dB | 0.153 | 0.000 LU | -0.842 dBTP | 121.7 | 220 MB |
| UniverSR (released weights) | **11.00 dB** | 0.463 | 0.000 LU | -0.836 dBTP | 0.41 | 2 776 MB |

Target set (the real MiniMax take, no reference):

| Arm | RTF | fizz flatness | loudness change | true peak |
|---|---|---|---|---|
| resample only | 47.47 | 0.0007 | -0.062 LU | -0.37 dBTP |
| UniverSR | 47.25 | 0.0007 | -0.062 LU | -0.37 dBTP |

**Both target numbers are identical because the model never ran**: the stage's report says
`"input already full band (22050 Hz) - resample only"`. The bandwidth rule (the highest frequency within
60 dB of the 1-4 kHz level) reads both real takes as full band - the MiniMax take at its Nyquist
(22 050 Hz), the YuE2 take at 21 949 Hz. An independent long-term spectrum shows why the rule is
permissive (levels relative to the 1-4 kHz band):

| Band | MiniMax take (44.1 kHz) | YuE2 take (48 kHz) |
|---|---|---|
| 10-14 kHz | -15.4 dB | -11.5 dB |
| 16-18 kHz | -27.5 dB | -21.3 dB |
| 18-20 kHz | -33.0 dB | -42.2 dB |
| 20-22 kHz | -37.8 dB | -54.2 dB |
| 22-24 kHz | (above Nyquist) | -69.2 dB |

So the MiniMax take is **not** brick-walled at ~14.5 kHz (the plan's "~32-kHz-class signal" assumption);
it decays smoothly and keeps low-level content to Nyquist, while the YuE2 take falls off a cliff above
~19 kHz. **Consequence:** with the shipped defaults, Refine's model engine adds nothing to these takes;
whether the MiniMax template should keep the model engine, force it (a stricter bandwidth rule) or drop
the block is a **design decision for the owner**, to be made on the blind material - not changed silently
here. Blind A/B material (band-limited input vs UniverSR, level-matched, fixed-seed order): 
`D:/Daten2/ComfyUI/output/plenio-l1-pack/2026-09-27 Words We Never Said (2) (original)/` with `key.json`
and `README.md`.
