## 3. Defects found by the tests and fixed

| Defect | Effect | Fix |
|---|---|---|
| The score session watched the document text with Vue's default (queued) flush, so its own writes were seen as external replacements | typing was never grouped into one undo step (every keystroke was a step), and every palette operation triggered a second, unnecessary analysis during which the view was marked pending | `watch(..., { flush: 'sync' })` in `useScoreSession.ts` |
| Playback compared times with 1 µs tolerance, but the backend rounds bar times to 3 and note times to 4 decimals | *Play from bar N* could skip the bar's first note (2.6667 < 2.667); the cursor showed two notes at a note boundary | shared `TIME_TOLERANCE` = 1 ms in `shared/playback.ts` (schedule, cursor, bar lookup in the transport); the shortest native note lasts 25 ms at 300 BPM |
| `display_abc` after an inline key change in a bar | readers disagree whether a bar's accidental survives `[K:...]`; abcjs could show a note a semitone off | the next note of such a letter is always written with its accidental |
| Chord refusal said "inside a Vocal note" for a rest too, without a hint | unclear message | "inside a longer Vocal note or rest" with a hint |

Each fix has a regression test; without the frontend fixes four Vitest tests fail.
