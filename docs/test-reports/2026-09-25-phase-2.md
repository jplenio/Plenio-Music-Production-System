## Findings that changed the design

1. **Promoted widgets:** the legacy `properties.proxyWidgets` form is quarantined by frontend 1.53 and the quarantined value overrides the saved value on reload. Blueprints must use subgraph inputs linked to inner widget inputs (current native format). The validator rejects `proxyWidgets`.
2. **Template browser category** is the install folder name, not the display name.
3. **Frontend types:** `@comfyorg/comfyui-frontend-types` 1.53.x/1.56.0 on npm contain no type file (and are GPL-3.0-only); Plenio declares the few shapes it needs itself.
4. **`locales/en` dropped:** English strings live only in the V3 schemas (one source of truth); `locales/` is for translations.
5. **pytest imports the package root `__init__.py`** as a package during collection; the entry point is loaded only when `__package__` is set (ComfyUI import).
6. **Hardware:** the host currently exposes one GPU and 32 GB RAM (the Phase 1A notes said two GPUs / 64 GB).
