## 6. Notes

- The bundled editor chunk (`web/js/chunks/open-*.mjs`) contains 15 control characters from abcjs string literals written raw by the minifier - the same count as in the previous build; not the heredoc pitfall the control-character scan guards against.
- File sizes of the writer and the adapter are not recorded (no public listing in the sources available here); the System Check shows the size on disk once installed.
- Licences of FLUX.2 Klein 4B (Apache-2.0) are from the design (VF); those of its text encoder and VAE are taken as Apache-2.0 from the model releases and should be confirmed on the model cards before a public release.

- CI (`.github/workflows/ci.yml`): the unit job did not install numpy/scipy/av/Pillow, which the unit tests of covers (4B) and the audio chain (7) import, and ran mypy with the 3.10 target that numpy's stubs break; both fixed. The CI results themselves are not visible from this session.
