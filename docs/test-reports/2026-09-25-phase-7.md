## 5. Restoration gate (C1)

`tools/studies/restoration_gate.py` measures clipping (samples at full scale, runs of 3+), inter-sample overs, spectral roll-off (highest frequency within 60 dB of the 1-4 kHz level), high-frequency balance (8-16 kHz vs. 1-4 kHz) and its spread over time. Result on the only take available in the cloud ([data](data/2026-09-25-phase-7/restoration-legacy-sample.json)):

| File | Loudness | True peak | Clipped runs | Roll-off | HF/mid |
|---|---|---|---|---|---|
| legacy MiniMax sample (241 s) | -13.95 LUFS | -0.96 dBTP | 0 | 21.0 kHz | -9.1 dB |

This file was mastered by the legacy toolkit (-14 LUFS, -1 dBTP), so it says nothing about raw model output. **Decision C1: provisional - no Repair node in Phase 7.** Nothing measured so far calls for declipping or de-harshing, and a repair stage without evidence would change every song. The final decision needs the script's numbers on **unprocessed** YuE2 and MiniMax takes (Export's `(original).flac` files or renders without mastering) from the owner's machine; if they show clipped runs or excessive HF fizz, the Repair node is added in a later phase with those takes as its test data.

## 6. Defects found and fixed

| # | Defect | Found by | Fix |
|---|---|---|---|
| D-1 | legacy resampler aliasing: a 23 kHz tone converted 48 -> 44.1 kHz came out at -6 dB as a 21.1 kHz alias | resampler stop-band test | band-edge Kaiser design (100 dB from the lower Nyquist frequency) |
| D-2 | the first true-peak interpolation filter missed the inter-sample-peak tests (the tests' unfaded tones also overshot at their edges) | true-peak tests | Kaiser low-pass designed from band edges 0.4/0.6 x rate, 80 dB; faded test tones |
| D-3 | Export's new format widgets were required, so existing API prompts (host tests of Phases 3-6) failed with "Required input is missing" | host suite | *flac*, *mp3*, *wav*, *tags* optional with defaults |
| D-4 | a *copy tags from file* combo would reject files uploaded after the node was created | design review | *copy from loaded file* reads the workflow's Load Audio file from the prompt |
| D-5 | 24-bit export scaled by 2^23-1: a 24-bit source came back with a tiny gain error, not sample-exact | bypass-identity host test | scale by 2^23 (decoder convention), clip at 2^23-1 |
| D-6 | Export reported the informational note *tags copied from ...* as a warning | browser run | notes are listed as info; only real problems (clipping, cover not embedded, WAV tag limits) make a warning |

## 7. Limitations (documented for users in [Mastering and audio formats](../user/concepts/mastering.md))

- True peak slightly under-reads content between 0.4 and 0.5 x the rate; the limiter keeps a 0.2 dB reserve.
- The EQ does not normalise; the tone match changes tone within ±*max gain*, never level.
- Loudness is whole-song; no fades, no multiband processing, no restoration.
- Cover embedding needs the optional GPL `mutagen` (never installed by Plenio); without it the cover is a JPEG next to the audio. WAV carries 7 tags and no cover.
