# Plenio 2.0.1

**Plenio Setup downloads on Linux and in containers again, where the first model folder is one ComfyUI may only read.**

> **New to Plenio?** Plenio is a free, open-source song production suite for ComfyUI that runs on your own PC: type an idea and get a finished, mastered song with cover art, timed lyrics and sheet music - sung by YuE2 or MiniMax Music 3. See and change every word, note and chord before it is sung, and play it to a room from the Plenio Player. [Listen first](https://jplenio.github.io/Plenio-Music-Production-System/) · [README](https://github.com/jplenio/Plenio-Music-Production-System#readme) · [Guide](https://jplenio.github.io/Plenio-Music-Production-System/guide/)

## Install

- **ComfyUI Manager**: search for *Plenio Music Production System* - or `comfy node install comfyui-plenio-music`.
- **The full download**: `git clone https://github.com/jplenio/Plenio-Music-Production-System` into `ComfyUI/custom_nodes`, or the zip below. It also carries the Studio add-on: the player starts ComfyUI, a `llama-server` runs a GGUF writer, *Open the folder* opens the file manager.

Restart ComfyUI: **Plenio Setup** opens and plans the model files for your graphics card.

## Every change

<details><summary><b>Fixed</b> (2)</summary>

- **Plenio Setup downloads into a model folder ComfyUI may write into.** It took the first folder ComfyUI registered for a kind of model; when that was a shared or system-wide one (from `extra_model_paths.yaml`, or a container's mount) that the user ComfyUI runs as may only read, every download stopped with *Permission denied*. Setup now takes the first folder of the kind it may write into, and step 3 lists that one as the target.
- **A folder it may not write into is said as such.** *Permission denied* read "another program is using the file - try again", which fits a virus scanner on Windows for a moment but never cures a missing right; trying again only downloaded the file anew. The download now stops with *ComfyUI may not write into this model folder* and says what helps: another of its folders, write access, or the file placed by hand.

</details>
